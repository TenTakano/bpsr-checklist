# デザイン共通方針

本プロジェクトの全画面に共通するデザインのトーン。各画面のデザインブリーフ（`docs/design/{slug}.md`）はこの方針を前提とする。

## トーン

- 実行型UI: 単一の派手なCTAで誘導せず、チェック操作そのものを主行動とする。日常的に繰り返し使う作業画面として、装飾より機能を優先する
- 俯瞰性最優先: キャラクター横断のマトリクスによる「俯瞰と記録の同時性」が本プロジェクトの独自価値。これを損なう構成変更（キャラごとのタブ分割・カード分割など）はしない
- 密度の使い分け: 作業領域（マトリクス）は高密度・最小構成の行で詰め、サマリー・集計領域はゆったりした余白を取る。余白の対比で操作頻度と重要度を表現する
- タイポグラフィはミニマル: 文字サイズの段階は3段程度に抑え、階層は極端なサイズ差ではなく太字の有無で作る
- 副CTAは視覚的重みを抑える: 枠線のみ・淡色・ホバー時のみ表示などで、主行動（チェック操作）より一段引かせる
- テーマ: ライト/ダーク両対応を全画面で維持する
